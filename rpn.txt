RPN.EXE              Reverse Polish Notation Calculator
-------------------------------------------------------
Written by:          Bruce Kelley  <no longer at Microsoft>
Current Owner:       Dan Lovinger  DanLo@microsoft.com
Date:                3 April 2000        Version-1.13

Platforms:           Intel versions of Windows

RPN is a Reverse Polish Notation calculator using a 4-level stack, similar
in operation to many Hewlett-Packard calculators.  It has two modes: Binary
and Floating Point.  The binary mode is great for hex/decimal/binary
calculations and conversions.  The floating point mode has all the operations
you would expect.  Each mode also has a "Help-Keys Mode" in which you can get
a pop-up description of what every key does.  Find this under the Help menu.

New in version 1.10: Save and restore the state and stack in the registry.

Fixed in version 1.11: Bug with window position that caused RPN to be
displayed off the screen.

New in version 1.12: word sizes 8/16/64 added, display cleanup, adorned
numbers, bunch of code collapsing between the float/binary calcs, enter mode
fixups for unary operators, unary add/subtract/shift operators on keyboard,
right shift is now arithmetic when signed integers are in use, use of HP-like
'!' flash to flag error as opposed to beeping.

New in version 1.13: tooltips, fixed decimal radix mode restore
